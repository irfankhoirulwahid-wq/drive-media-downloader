# Google Drive Media Downloader

Aplikasi Android untuk melihat dan mengunduh foto serta video dari folder Google Drive.

## Fitur
- Membaca folder Google Drive
- Menampilkan foto dan video
- Preview media
- Download satu atau banyak file
- Mendukung subfolder
- Antarmuka bahasa Indonesia

## Teknologi
- HTML
- CSS
- JavaScript
- Google Drive API v3
- Capacitor
